# 🌟 fyeris - Interactive Profile Web Page

背景で動画が自動再生し、閲覧者が遊んで楽しめるギミック（ミニゲームやおみくじ、クリック演出等）を搭載したインタラクティブなポートフォリオ・自己紹介Webサイトです。

---

## 📁 フォルダ構造 (Directory Structure)

ローカル環境やWebサーバーで運用する際は、以下のようにファイルを配置してください。

```text
profile/
├── README.md        # プロジェクト説明用ドキュメント (本ファイル)
├── index.html       # メインWebページ
├── css/
│   └── style.css    # スタイルシート（動画背景・Glassmorphism・アニメーション）
├── js/
│   └── script.js    # インタラクティブ機能（おみくじ・ミニゲーム・パーティクル）
└── img/
    ├── video.mp4    # 背景用動画ファイル (自動ループ再生)
    └── profile.jpg  # プロフィール画像 (3番目の人物イラスト)
```

---

## ✨ 主な機能と工夫点 (Features)

1. **背景自動再生動画 (`img/video.mp4`)**:
   - 背景全画面に動画を配置し、`autoplay` / `loop` / `muted` で自動再生。
   - テキストの可読性を保つため、半透明のガラス風（Glassmorphism）カードとグラデーションオーバーレイを採用。

2. **プロフィール画像 (`img/profile.jpg`)**:
   - 人物イラストをプロフィールアイコンとして設置。
   - ダブルクリックすると隠しメッセージ（イースターエッグ）が表示される裏技付き。

3. **閲覧者が楽しめるインタラクティブ要素**:
   - **どこでもクリックパーティクル**: 画面をクリックするたびに絵文字（✨, 🎮, 🚀など）が浮き上がる演出。
   - **今日の運勢おみくじ**: ヘッダーにあるボタンからおみくじを引けます。
   - **バグ退治ミニゲーム**: 画面内にランダム出現する「👾バグ」を10秒間で何匹撃破できるか競うミニゲーム。

---

## 🚀 使い方 (Setup Instructions)

1. **ファイルの配置**:
   - 背景に設定したい動画ファイルを `profile/img/video.mp4` として保存します。
   - プロフィールに指定したい人物イラストを `profile/img/profile.jpg` として保存します。

2. **ページの閲覧**:
   - `index.html` をダブルクリックするか、ブラウザにドラッグ＆ドロップして開きます。
